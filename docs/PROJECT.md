## 1. 项目简介

**技术内容自动发布 WordPress** 是一个基于 [n8n](https://n8n.io) 的自动化工作流，面向外网的 WordPress 技术类网站。它每 6 小时自动从 6 大技术主题中随机选题，由 DeepSeek 生成一篇 SEO/GEO 优化的原创文章，自动创建/复用分类与标签，检测重复后发布到 WordPress。

## 2. 核心价值

- **省时省力**：全自动选题、写作、发布。
- **内容多样**：6 大主题随机轮换，避免内容单调。
- **真实可靠**：提示词强制内容真实性，杜绝编造数据。
- **自动归类**：分类/标签自动创建与复用，零人工维护。
- **智能防重**：按 slug 查重，避免重复发布。

## 3. 覆盖主题

## 4. 工作流链路

```
Schedule Trigger (每6小时)
  → Code - 选题（6主题随机）
  → AI Agent（DeepSeek 生成 JSON）
  → Code - 解析AI输出
  → HTTP Request - 查重（按 slug 检测重复）
  → Code - 判断重复
  → IF - 是否重复
      ├─ 重复 → 结束（不发布）
      └─ 非重复 → Code - 准备术语（补齐默认标签）
            → HTTP - 创建分类 → Code - 取得分类ID
            → Code - 展开标签 → HTTP - 创建标签 → Code - 重组标签ID
            → Code - 组装发布参数
            → HTTP - 创建文章（发布到 WordPress REST API）
```

## 5. 功能特性

- **自动选题**：6 大主题随机轮换。
- **AI 生成**：DeepSeek 撰写原创技术文章，SEO/GEO 优化，输出结构化 JSON。
- **内容真实性约束**：提示词强制“不得编造版本号/价格/跑分/配置、以官方文档/官网为准”。
- **自动分类与标签**：分类/标签不存在时自动创建，存在时复用；标签不足时自动补齐默认标签（技术教程、实用技巧、网站运维），保证 ≥ 3 个。
- **重复文章检测**：按 slug 与已发布文章比对，重复则跳过。
- **断流防护**：HTTP 空数组响应、空标签等场景均不会导致链路中断。
